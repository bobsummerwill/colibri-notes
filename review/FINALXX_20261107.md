# Finalxx-style headline campaign, 6-PR DSV4 stack (2026-11-07)

Base: upstream `dev` at `e24cd51a`. Branches: `split-20261107/*`.
Machines: shadowfax (2×RTX 3090 24 GB, 62 GB RAM, CUDA 12.0, sm_86,
`NO_TC=1`) and computer4 (RTX 5070 12 GB, 62 GB RAM, CUDA 12.8, sm_120).

This is the headline round requested after the rebase. It uses the finalxx
protocol: cold server per sample, REAP `6×300` tokens, full V4 Flash `3×300`,
long-prefill TTFT, and a `1024×3` soak. Shadowfax ran two samples per arm;
computer4 ran one sample per arm (12 GB card, streaming-bound). Every request
is greedy and every text is SHA-256 compared across arms.

Models:

- REAP: `deepseek-v4-flash-reap` (85 GB) on both machines.
- Full: `deepseek-v4-flash` (156 GB) on both machines.

Server: `--ram 40 --ctx 8192`, `COLI_CUDA=1`, `COLI_GPU=0`,
`DSV4_CUDA_DEVICE=0`, `CUDA_DENSE=1`, `COLI_CUDA_PIPE=2`,
`COLI_CUDA_ATTN_BATCH=1`, `COLI_CUDA_MOE_BATCH=1`, `V4_MOE_REFILL_GROUP=12`,
`V4_LOADER_LANES=3`, `V4_PREFIX_CKPT_DISK=0`.

## Interpretation

- **#2664 is not a performance PR.** It only changes an error path and header
  linkage; the earlier 2.77 vs 3.28 was warm-up/order bias. It is the base for
  #2665–#2667 and is not benchmarked separately.
- **#2665 placement** adds 14.2 % REAP and 11.4 % full decode by raising usable
  cache capacity.
- **#2666 resident** is neutral on 24 GB and 12 GB: `auto` falls back to the LRU
  cache because the resident table exceeds the device budget. The PR is aimed
  at larger cards; the measured gain here is noise.
- **#2667 CUDA kernels** add 22.3 % REAP / 19.4 % full single-GPU, and 57.2 % /
  37.2 % with placement. This is the largest single-PR decode gain.
- **#2668 mirror/VRAM-first** is small but positive on 24 GB: +2.2 % REAP and
  +1.3 % full; neutral on 12 GB.
- **#2669 peer pool** adds 44.3 % REAP / 26.9 % full over single-GPU.
- **#2670 integration** combines both lanes: 1.225× / 1.576× / 1.958× REAP
  single/placement/peer, and 1.193× / 1.371× / 1.580× full. Long-prefill TTFT
  is ~11 % faster than dev; the 1024-token soak scales 3.60 → 4.68 → 5.88
  tok/s.
- The 5070 confirms the same ordering on sm_120: kernels/integration ~1.12–1.14×,
  resident/mirror neutral.
