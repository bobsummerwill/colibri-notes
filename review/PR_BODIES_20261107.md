## #2665

```markdown
## What this PR does

Multi-GPU layer placement for the V4 CUDA tier: `DSV4_CUDA_DEVICES` spreads decode layers over contiguous per-device ranges, and each layer's dense mirrors, attention KV and routed-expert mirrors live on the owning device. A KV-owner guard refuses a ring/compressor append addressed to a device that does not own the buffer.

This raises usable cache capacity; it is not tensor or pipeline parallelism — layers still execute sequentially.

## Where it came from

ZacharyZcR's [#1766](https://github.com/JustVugg/colibri/pull/1766) (`fc6f3c57`), rebased onto current `dev`; the KV-owner guard is from the head-followups fixes.

[#2666](https://github.com/JustVugg/colibri/pull/2666) and [#2667](https://github.com/JustVugg/colibri/pull/2667) build on it; [#2670](https://github.com/JustVugg/colibri/pull/2670) integrates it with [#2669](https://github.com/JustVugg/colibri/pull/2669).

## #2666

```markdown
## What this PR does

Resident routed experts and device routing: target experts are preloaded into immutable per-layer device tables, host loads are skipped for fully resident layers, and `DSV4_CUDA_RESIDENT_EXPERTS=auto` keeps the LRU cache on a budget refusal but rejects a hard failure (`1` requires residency, `0` keeps the cache). Routing, ascending expert-ID ordering and MoE run on the owning device stream; `DSV4_CUDA_RESIDENT_ROUTE=0` keeps host routing.

## Where it came from

ZacharyZcR's [#1766](https://github.com/JustVugg/colibri/pull/1766) (`893607e7`, `39685b0f`), rebased onto current `dev`; reserve/auto semantics from the head-followups fixes.

## Stack

3/6, based on [#2665](https://github.com/JustVugg/colibri/pull/2665). [#2667](https://github.com/JustVugg/colibri/pull/2667) builds on it; [#2670](https://github.com/JustVugg/colibri/pull/2670) integrates it.

## Headline

- REAP `6×300`: 2.986 tok/s vs dev 2.969 (+0.6%).
- Full `3×300`: 2.648 vs 2.623 (+1.0%).
- On 24 GB (and the 12 GB 5070) `auto` falls back to the LRU cache because the resident table exceeds the device budget, so the resident path does not engage; the gain is noise here. The PR targets larger cards.

Full details: [campaign](https://github.com/bobsummerwill/colibri-notes/blob/main/review/FINALXX_20261107.md) and [rebase/test round](https://github.com/bobsummerwill/colibri-notes/blob/main/review/TEST_ROUND_20261107.md).

```

The peer mirror pool and CUDA fault handling lane:
