## The important nuance

On 24 GB, both the full model and REAP log:

```text
resident experts exceed device 0 budget (free=16596/16768 MiB reserve=2800 MiB)
```

so `auto` falls back to the cache. The measured gain is from the faster kernels, not resident
experts. The bank-aware `mirror-reserve=4681MiB` line is present, but the preload path still uses
the flat 2800 MiB. `DSV4_CUDA_RESIDENT_EXPERTS=1` refuses cleanly with the same message; the
harness's `GATES: FAIL` is only that intentional negative control.

blockers. Remaining items:

   dev/#2405. Document the 24 GB fallback or split/rename the variable.
