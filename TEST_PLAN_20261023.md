## Step 1: final7 on shadowfax (llama and Hermes down; ~3.5 h)
Harness: final6's (`run_final6_main.sh`, `final6_tools.py`) as `final7`, same trees at the same commits (dev 7df8c27c,
pr1 b286167e, pr2 0523e8e0, f18 b62d1068 + the Vulkan builds), same base environment, fresh server per sample, texts
compared within a group. New: every Vulkan server runs with a cgroup memory cap (`MemoryMax=54G` on the transient unit),
so an OOM kills the sample, never another process on the box; the summary records each sample's memory peak and
`oom-kill` result. Order by value, so anything cut short is the least important:

| # | arms | model | question | pass |
|---|---|---|---|---|

  touching a line of either PR. Upstream CI already builds and tests #2264 on macOS and ARM ("All engines (macos)",
  "ARM ... NEON kernel exactness", both pass). Zebra also serves gemma-4-31B for the fleet. Worth it only as a separate
  question (V4 on Apple Silicon, or a Metal path for it).
- Windows, mixed-generation GPUs / P2P without NVLink, DeepGEMM on two GPUs: as in TEST_PLAN_20261022.md.
