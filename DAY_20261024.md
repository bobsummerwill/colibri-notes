## The two notes, read in the code (dev 61646cbd)
1. **`COLI_VK_UP_IMPORT` (imports slower than staged uploads on the RTX 3090).** The import path came with
   upstream #1925, whose description says "Not measured: the speed on a discrete card." Two defects:
   - `up_add_host` never counts its bytes toward the slot (`u->used`), so imports never trigger `up_submit`:
     every import of a commit lands in one command buffer, submitted at `up_finish`. `st_fill_group` commits up
     to 64 experts (192 matrices) at once precisely so the uploader's double-buffered 16 MiB slots overlap; with
     imports on, all pages are pinned first and copied after.
   - On NVIDIA an import costs ~0.4 ms of pin + unpin (`vkAllocateMemory` / `vkFreeMemory` of the imported
     range), more than the `memcpy` into the staging buffer it saves. On an Intel iGPU it costs ~0.002 ms.
2. **Pure-Vulkan texts vary run to run.** The docs say `COLI_VK_TIER_SYNC=1 COLI_VK_TIER_BALANCE=0` make a run
   reproducible (#2081), but the streaming rule `R = max(G, ceil(upload / cpu_row))` (`stream_min_rows`) still
   reads the measured upload rate and CPU time per row (R = 16 in one final15 run, 23 in another). final7 had
   6/6 identical texts with `COLI_VK_TIER_STREAM_ROWS=16 COLI_VK_TIER_BALANCE=0` pinned; final15 (unpinned) had 3
   different prompt-2 texts in 3 dev runs.

## Microbenchmark (tools/microbench/upbench.c)
Fresh `posix_memalign`'d 5 MiB images per tensor, one commit of G tensors, best of N. GB/s:

| commit | RTX 3090 (shadowfax GPU 1, llama idle beside it) | RTX 5070 (computer4) | Intel UHD 770 (computer4) |
|---|---|---|---|
| 1 expert (3 × 5 MiB): staged / import (dev) / import pipelined | **8.8** / 6.9 / 6.9 | **10.1** / 6.9 / 7.3 | 3.5 / 3.9 / **4.2** |
| 16 experts (48 × 5 MiB) | **12.4** / 6.6 / 10.0 | 11.3 / 7.7 / **12.1** | 7.2 / 6.1 / **8.7** |
| 64 experts (192 × 5 MiB) | **13.1** / 6.6 / 10.2 | 11.6 / 6.7 / **12.4** | 7.4 / 5.8 / **8.8** |
| 30 × 0.5 MiB | **8.8** / 2.1 / 2.1 | **10.4** / 4.1 / 4.3 | **3.0** / 2.8 / 2.7 |
| import + release per import | ~0.4 ms (release 0.25 ms) | ~0.45 ms | ~0.002 ms |

So: pipelining helps imports everywhere on groups (+50-80%); whether imports beat staging is device dependent.
